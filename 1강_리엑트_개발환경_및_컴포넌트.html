1 리엑트(React)란?

🎯 학습목표
  • 리엑트가 무엇을 위한 도구인지 한 문장으로 설명할 수 있다.
  • 리엑트가 프런트엔드 개발에서 차지하는 위치를 이해한다.

📖 리엑트(React) 개요

  • 리엑트는 사용자 인터페이스(UI, User Interface)를 구축하기 위한 자바스크립트 라이브러리이다.
  • 2013년 페이스북(현 메타, Meta)에서 처음 공개되었다.
  • 현재는 가장 널리 사용되는 프런트엔드 라이브러리로 자리 잡고 있다.

2 리엑트의 특징과 핵심 개념

🎯 학습목표
  • SPA(Single Page Application)의 동작 방식을 기존 웹 방식과 비교해 설명할 수 있다.
  • 리엑트의 4가지 핵심 특징(컴포넌트·가상돔·선언적·JSX)을 이해한다.

📖 SPA(Single Page Application)

SPA란 한 개의 HTML 페이지로 동작하는 웹 애플리케이션이다. 즉 페이지 이동이 없고 필요한 부분만 바뀐다.

🕸️ 기존 웹 방식

사용자 클릭 ↓ 서버 요청 ↓ 새 HTML 전체 응답 ↓ 페이지 새로고침
  • 화면 깜빡임
  • 느린 전환
  • 서버 의존적

⚡ SPA 방식

사용자 클릭 ↓ JavaScript 실행 ↓ 필요한 데이터만 요청 (API) ↓ 화면 일부만 변경
  • 빠른 화면 전환
  • 부드러운 UX
  • 클라이언트 중심

예) 쇼핑몰에서 [상품 목록] → 클릭 → [상품 상세] 이동 시, 페이지 이동 ❌ · URL만 변경 ⭕ · 내용만 교체 ⭕

📖 핵심 특징 ② 가상돔(Virtual DOM)

일반 JavaScript는 DOM을 직접 바꾼다. DOM이 바뀔 때마다 화면을 다시 그리므로(Reflow·Repaint), 요소가 많으면 느려지고 성능이 저하된다.

// 일반 JavaScript 방식 — DOM 직접 조작
document.getElementById("title").innerText = "Hello React";

리엑트는 메모리에 존재하는 가짜 DOM(Virtual DOM)을 사용해 이 문제를 해결한다.

[상태 변경] ↓ [새 Virtual DOM 생성] ↓ [이전 Virtual DOM과 비교] ↓ [바뀐 부분 찾기] ↓ [실제 DOM 최소 변경]

4 Node.js 설치 및 실행

🎯 학습목표
  • Node.js가 무엇이고 왜 필요한지 설명할 수 있다.
  • Node.js를 설치하고 node -v로 확인하며, JS 파일을 터미널에서 실행할 수 있다.

📖 Node.js란?

  • Node.js는 구글의 V8 JavaScript 엔진을 기반으로, 서버 측에서 JavaScript를 실행할 수 있도록 만든 오픈소스 런타임 환경이다.
  • 즉, 웹 브라우저 밖에서도 JavaScript를 실행할 수 있다.
  • 서버 작업 예: 웹 서버 만들기, API 서버 만들기, 파일 처리, 데이터베이스 연동

📖 Node.js의 특징

  • 비동기(Asynchronous) 처리
  • 싱글 스레드 이벤트 루프
  • NPM(Node Package Manager) 패키지 관리자 사용
    패키지 — 배포할 수 있도록 여러 모듈과 관련 파일을 묶어 놓은 것
💡 예제 — 서버 예시 코드
const http = require('http');
const server = http.createServer((req, res) => {
  res.write("Hello Node.js");
  res.end();
});
server.listen(3000);

📖 설치 및 확인

  • Node.js 공식 사이트에서 LTS 버전을 다운로드해 설치한다.
  • 설치 확인: 터미널에서 node -v (버전이 출력되면 성공)
  • npm 버전 확인: npm -v

5 JavaScript ES6 문법

🎯 학습목표
  • ES6가 무엇인지, 리엑트 개발에서 왜 중요한지 이해한다.
  • 템플릿 리터럴·화살표 함수·구조 분해·전개 연산자·map()을 사용할 수 있다.

📖 ES6(ECMAScript 2015)란?

  • ES6는 자바스크립트의 큰 업데이트로, 코드의 가독성·모듈화·생산성을 크게 개선한 문법과 기능이 추가되었다.
  • 현대 프런트엔드 개발(특히 React, Node.js)에서 기본적으로 사용되는 표준 문법이다.

주요 특징: let / const Template Literal Arrow Function Destructuring Spread / Rest (...) Module (export/import)

💡 예제 — 템플릿 리터럴 (literal.js)
// 템플릿 문자열
let season = '봄';

// 연결 연산자 - '+'
console.log('현재 계절은 ' + season + '입니다.');

// 백틱(`)으로 감싸고, ${}로 변수나 표현식을 감싸면 된다.
console.log(`현재 계절은 ${season}입니다.`);
💡 예제 — 화살표 함수 (function01.js)
// 함수 선언
let add = function (a, b) {
  return a + b;
}
console.log(add(10, 20));

// 화살표 함수
let add2 = (a, b) => {
  return a + b;
}
console.log(add2(10, 20));
// 매개변수가 하나인 경우, 괄호 생략 가능
let square = x => {
  return x * x;
}

/* 매개변수가 하나이고, 함수 본문이 한 줄인 경우,
   중괄호와 return 생략 가능 */
let square2 = x => x * x;

console.log(square(5));
console.log(square2(5));

// 매개변수 없는 경우
let message = () => console.log('Good, Luck!');
message();
💡 예제 — 구조 분해 할당 (destructure.js)
// 배열 구조 분해 할당
const arr = [1, 2];
console.log(arr[0]); //1
console.log(arr[1]); //2

const [a, b] = arr;
console.log(`a: ${a}`); //a: 1
console.log(`b: ${b}`); //b: 2

// 객체 구조 분해 할당
const product = {
  name: '무선마우스',
  price: 27000
};

const { name, price } = product;
console.log(`제품명: ${name}`);
console.log(`가격: ${price}`);
💡 예제 — Spread / Rest 연산자 (...)
// 배열에서 사용
let arr1 = [1, 2, 3];
let arr2 = [4, 5];

// 배열을 펼쳐서 새로운 배열을 만든다.
let newArr = [...arr1, ...arr2];
console.log(newArr);

// 객체에서 사용
let obj1 = { product: '무선마우스', price: 27000 };
let obj2 = { spec: 'M200 무선마우스 그레이' };

// 객체를 펼쳐서 새로운 객체를 만든다.
let combinedObj = { ...obj1, ...obj2 };
console.log(combinedObj);

💡 예제 — 배열 메서드 map()

배열의 각 요소에 대해 주어진 함수를 호출한 결과를 모아 새로운 배열을 반환하는 함수

// 배열의 각 요소를 2배로 만드는 예시
const arr = [1, 2, 3];

const newArr = arr.map(x => x * 2);
console.log(newArr); // [2, 4, 6]

// 객체 배열에서 특정 속성만 추출하기
const users = [
  { name: 'Jerry', age: 25 },
  { name: 'Linda', age: 30 },
  { name: 'Tom', age: 35 }
];

const names = users.map(user => user.name);
console.log(names); // ['Jerry', 'Linda', 'Tom']

const ages = users.map(user => user.age);
console.log(ages); // [25, 30, 35]

실습 5-1. 화살표 함수 + 템플릿 리터럴

두 수를 받아 합을 "합계: N" 형식의 문자열로 반환하는 화살표 함수 sum을 작성하고, sum(3, 7)의 결과를 출력하세요.

정답 보기 
const sum = (a, b) => `합계: ${a + b}`;
console.log(sum(3, 7)); // 합계: 10

본문이 한 줄이면 중괄호와 return을 생략할 수 있고, 백틱과 ${}로 값을 문자열에 끼워 넣는다.

6 모듈 시스템 (CommonJS vs ES)

🎯 학습목표
  • 모듈의 개념을 이해하고, 두 가지 모듈 시스템을 구분할 수 있다.
  • module.exports/require와 export/import를 사용해 코드를 나눌 수 있다.

📖 Node.js 모듈

  • 모듈이란? 프로그램을 작은 기능 단위로 쪼개고 파일 형태로 저장해 놓은 것
  • CommonJS 모듈 시스템 — Node.js의 기본 모듈 시스템 (require, module.exports 사용)
  • ES 모듈 시스템 — ECMAScript의 표준 모듈 시스템 (import, export 사용)
💡 예제 — CommonJS 모듈 시스템
lib/basicModule.js 
// 제곱수 계산
let square = function(x){
  return x * x
}

// 절대값 계산
let myAbs = function(x){
  if (x < 0) {
    return -x;
  } else {
    return x;
  }
}

// module.exports = square;   // 1개만 내보낼 때
module.exports = { square, myAbs }; // 2개 이상 내보낼 때
main-1.js 
// CommonJS 모듈 가져오기
// let square = require("./lib/basicModule.js")
let { square, myAbs } = require("./lib/basicModule.js")

console.log(square(4)); //16
console.log(myAbs(-5)); //5
console.log(myAbs(5)); //5

📖 ES 모듈 시스템 준비

  • package.json에 "type": "module" 속성을 추가해야 한다.
  • package.json은 npm init -y 명령으로 만들 수 있다.
package.json 
{
  "name": "web",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "type": "module",
  "author": "",
  "license": "ISC",
  "description": "",
  "dependencies": {
    "ansi-colors": "^4.1.3"
  }
}
💡 예제 — ES 모듈 시스템
lib/esModule.js 
let square = function(x) {
  return x * x;
}

let myAbs = function(x) {
  if (x < 0) {
    return -x;
  } else {
    return x;

// export { square }; //square 함수만 내보내기

main-2.js

// import { square } from "./lib/esModule.js";  //{} 필수

📖 전체 실행 과정

  1. npm run dev로 서버를 실행한다.
  2. 서버는 index.html 파일을 연다.
  3. index.html은 main.jsx 파일을 불러온다.
  4. main.jsx에서 App 컴포넌트를 읽어 실행한다.
  5. App 컴포넌트가 웹 브라우저 화면에 표시된다.

📖 JSX(JavaScript XML)란? — JSX vs HTML

JSX는 HTML과 매우 비슷하게 생겼지만 실제로는 JavaScript 문법의 확장이다. 그래서 개발할 때 몇 가지 중요한 차이점이 있다.

구분HTMLJSX
클래스classclassName
태그 구조여러 태그 가능하나의 부모 요소 필요
태그 닫기일부 생략 가능반드시 닫아야 함
JS 사용불가능{ } 안에서 가능
이벤트onclickonClick

9 컴포넌트(Component)

🎯 학습목표
  • 컴포넌트를 정의하고 다른 컴포넌트 안에서 태그처럼 사용할 수 있다.
  • 인라인 스타일을 객체로 적용할 수 있고, 컴포넌트를 별도 파일로 분리할 수 있다.
💡 예제 — 컴포넌트 정의와 사용

컴포넌트 이름은 대문자로 시작한다. 정의한 컴포넌트는 <MyButton />처럼 태그로 사용한다.

function MyButton() {
  return (
    <button>
      목록 보기
    </button>
  );
}
function App() {

  return (
    <>
      <div>
        {/* 인라인 스타일 적용 */}

          style={{
            color: 'red',
            fontWeight: 'bold'

        >Hello, World!</h1>
      </div>

      <div className="welcome">
        <h2>Welcome~ <br /> 홈페이지 방문을 환영합니다!</h2>
      </div>
      {/* 버튼 컴포넌트 사용 */}
      <MyButton />
    </>
  )
}

10 조건부 렌더링

🎯 학습목표
  • 조건에 따라 다른 화면을 보여주는 3가지 방법(if · 삼항 연산자 · && 연산자)을 사용할 수 있다.
💡 예제 — Example01.jsx (조건부 렌더링)
src/components/Example01.jsx 
const Example01 = () => {
  const isLoggedIn = true;

  /*
  if문 사용
  let result = "";

  if(isLoggedIn){
    result = "로그인 상태입니다.";
  }else{
    result = "로그아웃 상태입니다.";
  }
  */

  return(
    <div>
      <h2>조건부 렌더링</h2>
      {/* <p>{result}</p> */}
      {/* 삼항 연산자 사용 */}
      {isLoggedIn ?
        <p>로그인 상태입니다.</p> :
        <p>로그아웃 상태입니다.</p>}

      {/* && 연산자 사용 */}
      {isLoggedIn && <p>로그인 상태입니다.</p>}
    </div>
  )
}

export default Example01

12 이벤트 핸들링

🎯 학습목표
  • 이벤트 핸들러의 개념을 이해하고, 함수 참조·인라인 핸들러를 구분해 사용할 수 있다.
  • 매개변수가 있는 함수를 이벤트에 연결하고, 이벤트 객체를 활용할 수 있다.

📖 이벤트 핸들러

  • 이벤트 핸들러는 이벤트가 발생했을 때 실행할 함수이다.
  • 함수 참조 — 컴포넌트 안(밖)에 함수를 따로 정의하고 이름만 연결하는 방식
  • 인라인 핸들러 — 이벤트 속성 안에 함수를 직접 작성하는 방식
💡 예제 — Example03.jsx (이벤트 핸들링)
src/components/Example03.jsx 
const Example03 = () => {
  // 이벤트 핸들링
  const handleClick = () => {
    alert('버튼이 클릭되었습니다!');
  }

  const greet = (name) => {
    alert(`안녕하세요, ${name}님!`);
  }

  // 폼 요소와 이벤트 핸들링
  const handleInputChange = (event) => {
    console.log(event); // 이벤트 객체 전체 출력
    // 입력된 값 출력
    console.log(event.target.value);
  }

  return (
    <div>
      <h1>Example 03</h1>
      <p>이것은 예제 03입니다.</p>
      {/* 이벤트 핸들링 - 클릭 이벤트 */}
      <button onClick={handleClick}>클릭하세요</button>
      <br />
      {/* 화살표 함수를 사용한 이벤트 핸들링 */}
      <button onClick={() => greet('김도영')}>인사하기1</button>
      <br />
      <br />
      {/* 폼 요소와 이벤트 핸들링 - 입력 이벤트 */}
      <input type="text" onChange={handleInputChange} />
    </div>
  )
}
💡 핵심 — onClick={handleClick}처럼 함수 이름만 넘긴다(괄호를 붙이면 즉시 실행됨). 인자를 넘길 때는 onClick={() => greet('김도영')}처럼 화살표 함수로 감싼다.
💡 예제 — 매개변수가 있는 함수 연결
// 절댓값을 구하는 함수
const handleMyAbs = (x) => {

  if (x < 0) {
    console.log(-x)
  } else {
    console.log(x)
  }
}
<button
  onClick={
    () => handleMyAbs(-5)

</button>

13 리엑트 Props

🎯 학습목표
  • props로 부모 컴포넌트가 자식 컴포넌트에 값을 전달하는 원리를 이해한다.
  • props를 받는 3가지 표현(props / 구조 분해 / 매개변수 구조 분해)과 객체·children 전달을 사용할 수 있다.

📖 Props란?

  • props(properties)는 컴포넌트를 마치 HTML 태그처럼 사용해 값을 속성 형태로 전달한다.
  • 문자열은 따옴표로, 숫자는 중괄호 안에 넣어서 전달한다.
src/App.jsx 
<div>
  <h2>리엑트 상태 관리</h2>
  <Dog
    breed="말티즈"
    age={2}
  />
  <Dog
    breed="포메라니안"
    age={3}
  />
</div>
💡 예제 — Props 받는 3가지 표현 (Dog.jsx)

표현 1 — props 객체를 그대로 받아 props.속성으로 사용

export default function Dog(props) {

const Dog = (props) => {

14 종합 실습 — 프로필 카드 UI

🎯 학습목표
  • 지금까지 배운 컴포넌트·props·children을 조합해 프로필 카드 UI를 구현할 수 있다.
💡 STEP 1 — 단순 Profile 컴포넌트

먼저 하나의 컴포넌트 안에서 user 객체를 만들어 이름과 사진을 보여준다.

src/Profile2.jsx 
import profilePhoto from '../assets/giyong.jpg'

const Profile = () => {
  const user = {
    name: "김기용",
    imageUrl: profilePhoto
  }

  return(
    <div>
      <h1>{user.name}</h1>
      <img
        src={user.imageUrl}
        alt={'Photo of' + user.name}
        className='profile-photo'
      />
    </div>
  )
}
App.css 
body{
  background-color: #f0f0f0;
  margin: 0;
  padding: 20px;
}

.profile-photo{
  width: 160px;
  height: 160px;
  border-radius: 50%;
}

border-radius: 50%로 정사각형 이미지를 원형으로 만든다.

📖 STEP 2 — 컴포넌트 분리 개요

  • 파일명: src/card/Profile.jsx
  • 주요 목적: 프로필 카드 UI 표시 (이미지 + 정보)
  • 구성 컴포넌트: Profile, Avatar, Card
Profile (전체 프로필 페이지) └ Card (카드 형태의 틀 — children을 감쌈) └ Avatar (person 객체를 받아 프로필 사진 표시)
💡 STEP 3 — Profile.jsx (프로필 페이지)
src/card/Profile.jsx 
/*
  프로필 페이지를 보여주는 컴포넌트입니다.
  Card 컴포넌트를 사용하여, Avatar 컴포넌트를
  카드 형태로 보여줍니다.
*/
const Profile = () => {

  return(
    <Card>
      {/* <h2>Card UI 구현</h2> */}
      <Avatar
        person={{
          name: '김기용',
          imageUrl: profilePhoto
        }}
      />
    </Card>
  )
}
💡 STEP 4 — Avatar.jsx (프로필 사진)
src/card/Avatar.jsx 
/*
  프로필 사진을 보여주는 컴포넌트입니다.
  props로 person 객체를 받아서, person 객체의
  imageUrl과 name을 사용하여 프로필 사진을 보여줍니다.
*/
export default function Avatar({person}) {

  return(
    <div>
      {/* <h3>여기에 프로필 사진</h3> */}
      <div>
        <img
          src={person.imageUrl}
          alt={person.name}
          width={400}
          className="avatar"
        />
      </div>
    </div>
  )
}
💡 STEP 5 — Card.jsx (카드 틀)
src/card/Card.jsx 
/*
  카드 형태의 UI를 만들어주는 컴포넌트입니다.
  props로 children을 받아서, children을 카드 컴포넌트의
  내용으로 보여줍니다.
*/
export default function Card({children}){

  return(
    <div className="card">
      { /* 카드 컴포넌트의 모든 내용 */ }
      {children}
    </div>
  )
}
💡 STEP 6 — App.css (스타일)
src/App.css 
/*
img 태그는 기본적으로 inline 요소라서
텍스트 베이스라인에 맞춰 렌더링되는데,
이 때문에 이미지 아래에 영문 소문자
내려쓰기(descender) 공간만큼 여백이 생깁니다. */
.avatar{
  /* inline 요소를 block 요소로 변경하여 여백 제거 */
  display: block;
  border-radius: 5px;
}
.card{
  border: 3px solid #06cccc;
  border-radius: 10px;
  max-width: 400px; /* Card는 최대 400px까지만 커짐 */
  padding: 10px;
  margin: 10px auto;
}

실습 14-1. 나만의 프로필 카드

위 Profile / Avatar / Card 구조를 활용해, 본인의 이름과 사진으로 프로필 카드를 완성하세요. (이미지가 없으면 임의 URL 또는 색상 박스로 대체)

힌트 보기

① Avatar에 넘기는 person 객체의 name·imageUrl만 본인 정보로 바꾸면 된다. ② Card는 children을 감싸는 틀이므로 수정할 필요가 없다. ③ 사진 대신 배경색 박스를 쓰려면 Avatar의 <img>를 <div className="avatar" style={{width:200,height:200,background:'#8ec5ff'}}></div>로 바꾼다.
