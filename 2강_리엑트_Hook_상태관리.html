1 리엑트 Hook이란?

🎯 학습목표
  • Hook의 개념과 필요성을 설명할 수 있다.
  • useState의 반환값(상태 변수·상태 변경 함수)을 구분할 수 있다.

📖 Hook의 개념

  • 리엑트에서는 상태를 관리할 때 훅(Hook)을 사용한다.
  • 훅이란 함수형 컴포넌트에서 상태(state)와 생명주기(lifecycle)를 쉽게 관리할 수 있도록 도와주는, 리엑트가 제공하는 특별한 함수이다.
  • 주요 함수로는 useState(), useEffect(), useRef() 등이 있다.

📖 useState 기본 형태

const [state, setState] = useState(0)
  • state: 상태 값을 저장하는 변수. 보통 상태 변수라고 부른다.
  • setState: 상태를 변경하는 함수. 상태 변경 함수라고 부른다.
  • useState(0)의 0은 초기값이다.

예) count 상태를 관리하는 코드

const [count, setCount] = useState(0)

2 useState — Counter 만들기

🎯 학습목표
  • 버튼 클릭으로 숫자 상태를 증가·감소·초기화할 수 있다.
  • 인라인 핸들러와 함수 참조 방식을 함께 사용할 수 있다.
💡 예제 — Counter.jsx
src/components/Counter.jsx 
import { useState } from "react";

const Counter = () => {
    // 초기화 필수 : const count = 0
    const [ count, setCount ] = useState(0);

    // 숫자 1 증가 핸들러(함수)
    const increment = () => {
        setCount(count + 1);
    }

    // 숫자 1 감소 핸들러(함수)
    const decrement = () => {
        setCount(count - 1);
    }

    return(
        <div>
            <h2>카운터 만들기</h2>
            <h3>현재 Count: {count}</h3>
            <button onClick={increment}>+증가</button>
            <button onClick={decrement}>-감소</button>
            {/* 인라인 핸들러 사용 예시 */}
            <button onClick={() => setCount(0)}>초기화</button>
        </div>
    )
}
export default Counter;
브라우저 출력
카운터 만들기
현재 Count: 2
💡 핵심 — 상태를 바꿀 때는 count = count+1처럼 직접 바꾸지 않고 반드시 상태 변경 함수 setCount(...)를 호출한다. 그래야 리엑트가 화면을 다시 그린다.

3 useState — 입력값 변경 컴포넌트

🎯 학습목표
  • 입력창의 값을 문자열 상태로 관리할 수 있다.
  • onChange 이벤트와 event.target.value로 입력값을 상태에 반영할 수 있다.
💡 예제 — InputValue.jsx
src/components/InputValue.jsx 
import { useState } from "react";

// 입력값 변경 컴포넌트 정의
const InputValue = () => {
    // 빈 문자열 초기화
    const [text, setText] = useState("");

    // 입력값 변경 함수
    const handleInputChange = (event) => {
        setText(event.target.value);
        //console.log(event.target.value);
    }

    return(
        <div>
            <h2>입력값 변경</h2>
            <div>
                <input 
                    type="text" 
                    placeholder="글자를 입력하세요"
                    value={text}
                    onChange={handleInputChange}
                />
                <p>입력값: {text}</p>
            </div>
        </div>
    )
}

export default InputValue;

4 useState — 객체 상태 관리

🎯 학습목표
  • 객체를 상태로 관리하고, 전개 연산자로 특정 속성만 안전하게 변경할 수 있다.
💡 예제 — 자동차 연식 업데이트 (Car.jsx)
src/components/Car.jsx 
const Car = () => {
  const [car, setCar] = useState({
    brand: '현대',
    model: '쏘나타',
    year: 2020
  });

  const updateYear = () => {
    /* car 객체의 year 속성만 업데이트하기 위해
       기존의 car 객체를 복사하고 year 속성만 변경 */
    setCar({ ...car, year: 2025 });
  };

  return (
    <div>
      <h2>자동차 컴포넌트</h2>
      <p>브랜드: {car.brand}</p>
      <p>모델: {car.model}</p>
      <p>연식: {car.year}</p>
      <button onClick={updateYear}>연식 업데이트</button>
    </div>
  );
}
브라우저 출력 (버튼 클릭 후)
자동차 컴포넌트
브랜드: 현대
모델: 쏘나타
연식: 2025
⚠️ 주의 — 객체 상태는 setCar({ ...car, year: 2025 })처럼 기존 객체를 복사(...car)한 뒤 바꿀 속성만 덮어써야 나머지 속성이 사라지지 않는다.

5 useState — 배열 상태 관리

🎯 학습목표
  • 배열을 상태로 관리하고, 전개 연산자로 항목을 추가할 수 있다.
  • 입력 필드의 값을 상태로 관리(제어 컴포넌트)하고 map()으로 목록을 렌더링할 수 있다.
💡 예제 ① — 고정 배열에 항목 추가 (Drinks.jsx)
src/components/Drinks.jsx 
import { useState } from "react";

const Drinks = () => {
  //음료 배열 상태 관리 - 초기화
  const [drinks, setDrinks] = useState(['커피', '콜라']);

  const addDrink = () => {
    //기존 drinks 배열에 '딸기쥬스'를 추가하여 새로운 배열 생성
    setDrinks([...drinks, '딸기쥬스'])
  }

  return(
    <div>
      <h2>음료 추가</h2>
      <h4>현재 음료: {drinks.join(', ')}</h4>
      <button onClick={addDrink}>음료 추가</button>
    </div>
  )
}
브라우저 출력 (버튼 클릭 후)
현재 음료: 커피, 콜라, 딸기쥬스
💡 예제 ② — 입력값으로 항목 추가 (Drinks2.jsx)
src/components/Drinks2.jsx 
const Drinks2 = () => {
  const [drinks, setDrinks] = useState([]);
  //입력 필드의 상태 관리
  const [inputValue, setInputValue] = useState('');

  const addDrink = () => {
    const newDrink = inputValue.trim();
    if(newDrink == ''){
      alert('음료 이름을 입력하세요');
      return;
    }
    //새 음료를 기존 배열에 추가
    setDrinks([...drinks, newDrink]);
    setInputValue('');  //입력 필드 초기화
  }

  return (
    <div>
      <h2>음료 추가</h2>
      <input
        type="text"
        placeholder="음료 이름을 입력하세요"
        value={inputValue}
        onChange={(e) => setInputValue(e.target.value)}
      />
      <button onClick={addDrink}>음료 추가</button>
      {/* <p>입력값: {inputValue}</p> */}

      <ul>
        {drinks.map((drink, index) => (
          <li key={index}>{drink}</li>
        ))}
      </ul>
    </div>
  )
}
💡 제어 컴포넌트 — <input>의 value를 상태와 묶고 onChange로 상태를 갱신하면, 입력값을 리엑트가 완전히 제어한다. 이것을 제어 컴포넌트(Controlled Component)라고 한다.

7 종합 실습 — 할 일 관리(Todo App)

🎯 학습목표
  • 객체 배열 상태로 할 일 목록을 관리(추가·완료 토글·삭제)할 수 있다.
  • map·filter로 배열 상태를 불변성 있게 업데이트하고, 목록을 컴포넌트로 분리할 수 있다.
💡 STEP 1 — 상태와 입력 핸들러 (App.jsx)
src/App.jsx 
function App() {
  const [todos, setTodos] = useState([
    { id: 1, text: '운동 하기', completed: false },
    { id: 2, text: '영화 보기', completed: false },
  ])
  const [inputValue, setInputValue] = useState('')

  console.log(todos.length); //2

  // 입력값 변경 핸들러
  const handleInputChange = (e) => {
    console.log(e.target.value);
    setInputValue(e.target.value)
  }
💡 STEP 2 — 할 일 추가
  // 할 일 추가
  const handleAddTodo = () => {
    if (inputValue.trim() !== '') {
      // 새로운 할 일 객체 생성
      const newTodo = {
        id: todos.length + 1,
        text: inputValue,
        completed: false,
      }
      // 새로운 할 일을 기존 할 일 목록에 추가
      setTodos([...todos, newTodo])
      setInputValue('') // 입력 필드 초기화
    }
  }
💡 STEP 3 — 완료 토글 · 삭제
  // 할 일 완료 체크
  const handleToggleComplete = (id) => {
    /* 해당 id를 가진 할 일의 completed 상태를 토글
       todos 배열을 순회하면서 id가 일치하는 할 일의 completed 값을 반전시킴
       id가 일치하지 않는 할 일은 그대로 유지 */
    setTodos(
      todos.map((todo) =>
        todo.id === id ? { ...todo, completed: !todo.completed } : todo
      )
    )
  }

  // 할 일 삭제
  const handleDeleteTodo = (id) => {
    /* 해당 id를 가진 할 일을 삭제
       todos 배열을 필터링하여 id가 일치하지 않는 할 일만 남김 */
    setTodos(todos.filter((todo) => todo.id !== id))
  }
💡 STEP 4 — 화면 렌더링 (한 파일 버전)
  return (
    <>
      <div className='container'>
        <h2>Todo List</h2>
        <input
          type="text"
          value={inputValue}
          onChange={handleInputChange}
          placeholder="할 일을 입력하세요"
        />
        <button onClick={handleAddTodo}>추가</button>

        {/* 할 일 목록 */}
        <ul className='todo-list'>
          {todos.map((todo) => (
            <li key={todo.id} className={todo.completed ? 'completed' : ''}>
              <input
                type="checkbox"
                checked={todo.completed}
                onChange={() => handleToggleComplete(todo.id)}
              />
              {todo.text}
              <button onClick={() => handleDeleteTodo(todo.id)}>삭제</button>
            </li>
          ))}
        </ul>
      </div>
    </>
  )
}

8 useEffect() 사이드 이펙트

🎯 학습목표
  • useEffect가 무엇을 위한 훅인지, 사이드 이펙트의 종류를 설명할 수 있다.
  • 의존성 배열의 의미([] / [값])를 구분해 사용할 수 있다.

📖 useEffect란?

  • useEffect 훅은 함수형 컴포넌트에서 사이드 이펙트(side effect)를 처리하기 위한 핵심 훅이다.
  • 리엑트 컴포넌트는 순수한 렌더링 함수여야 하지만, 현실에서는 외부 세계와 상호작용해야 할 때가 있다. useEffect는 그 부수 효과를 처리하기 위해 존재한다.
종류예시
데이터 패칭 (API 호출)fetch(), axios.get()
DOM 직접 조작document.title …
이벤트 등록addEventListener()
타이머setTimeout(), setInterval()

📖 기본 형태와 의존성 배열

useEffect(() => {
  // 실행할 코드
}, [의존성]);

useEffect(() => {
  console.log("count 변경됨");
}, [count]);
의존성 배열실행 시점
[] (빈 배열)처음 렌더링될 때 한 번만 실행
[age] (값 있음)처음 + age가 변경될 때마다 실행
생략매 렌더링마다 실행
💡 예제 ① — 타이머로 만드는 디지털 시계 (Clock.jsx)
src/components/Clock.jsx 
export default function Clock(){
  // time 상태 관리
  const [time, setTime] = useState(new Date().toLocaleTimeString());

  //처음 렌더링될때 타이머 설정
  useEffect(() => {
    const timer = setInterval(() => {
      setTime(new Date().toLocaleTimeString());
    }, 1000)
    console.log("렌더링...");

  },[])

  return(
    <div>
      <h2>디지털 시계</h2>
      <h3>현재 시간: {time}</h3>
    </div>
  )
}
브라우저 출력
디지털 시계

💡 참고 — 빈 배열 []이므로 setInterval은 처음 한 번만 등록되고, 1초마다 time 상태가 갱신되어 화면이 다시 그려진다. (실무에서는 useEffect의 return () => clearInterval(timer)로 정리(cleanup) 코드를 넣어 타이머를 해제한다.)
💡 예제 ② — 특정 값이 바뀔 때 실행 (User.jsx)
src/components/User.jsx 
import { useEffect, useState } from 'react';

const User = () => {
  const [name, setName] = useState("");
  const [age, setAge] = useState(1);

  // [] -> 처음 렌더링될 때만 실행
  // [age] -> age가 변경될 때마다 실행
  useEffect(() => {
    console.log("렌더링..");
    console.log(`이름: ${name}, 나이: ${age}`);
  }, [age]);

  // 이름을 변경하는 이벤트 핸들러 함수
  const onChangeName = (e) => {
    setName(e.target.value);
  }

  // 나이를 변경하는 이벤트 핸들러 함수
  const onChangeAge = (e) => {
    setAge(Number(e.target.value));
  }

  return (
    <div>
      <h2>사용자 정보</h2>
      <input
        type="text"
        value={name}
        onChange={onChangeName}
      />
      <br />
      <input
        type="number"
        value={age}
        onChange={onChangeAge}
      />
      <p>이름: {name}</p>
      <p>나이: {age}</p>
    </div>
  )
}
💡 관찰 — 이름을 입력해도 콘솔의 렌더링..은 찍히지 않고, 나이(age)를 바꿀 때만 useEffect가 실행된다. 의존성 배열에 age만 넣었기 때문이다.

  • name 속성을 이용해 하나의 핸들러로 모든 필드를 처리하고, 폼 제출을 제어할 수 있다.
💡 STEP 1 — 상태와 공통 핸들러 (SignUp.jsx)
src/components/SignUp.jsx 
const SignUp = () => {
  // 폼 데이터 상태 관리
  const [formData, setFormData] = useState({
    name: "",
    job: "회사원",
    gender: "male",
    memo: ""      //자기 소개
  });

  // 모든 입력 필드의 변경을 처리하는 함수
  const handleInputChange = (e) => {
    const {name, value} = e.target;

    setFormData({
      ...formData,
      [name]: value //name 속성: 값
    });
  }

  // 폼 제출을 처리하는 함수
  const handleSubmit = (e) => {
    e.preventDefault();
    console.log("제출 데이터: ", formData);

    // 입력 필드 초기화
    setFormData({
      name: "",
      job: "회사원",
      gender: "male",
      memo: ""
    });
  }
💡 핵심 기법 — 각 입력에 name을 주고 [name]: value(계산된 속성명)를 쓰면, 필드마다 핸들러를 따로 만들 필요 없이 하나의 handleInputChange로 모두 처리할 수 있다.
💡 STEP 2 — 폼 렌더링
  return(
    <div className="sign-up">
      <h2>회원 가입</h2>
      <form onSubmit={handleSubmit}>
        <ul>
          <li>
            <label>이름</label>
            <input 
              type="text"
              name="name"
              value={formData.name}
              onChange={handleInputChange}
            />
          </li>
          <li>
            <label>직업</label>
            <select
              name="job"
              value={formData.job}
              onChange={handleInputChange}
            >
              <option value="employee">회사원</option>
              <option value="student">학생</option>
              <option value="freelancer">프리랜서</option>
            </select>
          </li>
          <li>
            <label>성별</label>
            <label><input 
              type="radio"
              name="gender"
              value="male"
              checked={formData.gender === "male"}
              onChange={handleInputChange}
            />남자</label>
            <label><input 
              type="radio"
              name="gender"
              value="female"
              checked={formData.gender === "female"}
              onChange={handleInputChange}
            />여자</label>
          </li>
          <li>
            <label>자기소개</label>
            <textarea 
              name="memo" 
              rows={5}
              column={10}
              value={formData.memo}
              onChange={handleInputChange}
            />
          </li>
          <li>
            <button type="submit">가입</button>
          </li>
        </ul>
      </form>
    </div>
  )
}

10 로그인 폼 — 검증 처리

🎯 학습목표
  • 임시 사용자 데이터와 find()로 로그인 성공/실패를 검증할 수 있다.
  • 검증 결과에 따라 조건부로 메시지를 렌더링할 수 있다.
💡 STEP 1 — 데이터·상태·핸들러 (SignIn.jsx)
src/components/SignIn.jsx 
import { useState } from "react";

const users = [
  {username: "user1", password: 'user1111'},
  {username: "user2", password: 'user2222'},
  {username: "admin", password: 'admin0000'},
]

const SignIn = () => {
  const [formData, setFormData] = useState({
    username: "",
    password: ""
  });

  //로그인 결과 상태 관리
  const [result, setResult] = useState(null);

  const handleInputChange = (e) => {
    const {name, value} = e.target;

    setFormData({
      ...formData,
      [name]: value
    })
  }

  const handleSubmit = (e) => {
    e.preventDefault(); //기본 동작 막기
    console.log("제출 데이터: ", formData);

    // 로그인 결과 처리
    const {username, password} = formData;

    // 데이터 일치 여부
    // find() - 조건에 맞는 첫 요소를 반환하고, 없으면 undefined를 반환한다.
    const matched = users.find((user) => 
      user.username === username && user.password === password);

    // 로그인 성공여부에 따라 결과 상태 업데이트
    setResult(matched ? "success" : "fail");

    // 입력 필드 초기화
    setFormData({username: "", password: ""});
  }
💡 STEP 2 — 검증 · 조건부 메시지
  return(
    <div className="sign-in">
      <h2>로그인</h2>
      <form onSubmit={handleSubmit}>
        <ul>
          <li>
            <input 
              type="text"
              name="username"
              value={formData.username}
              onChange={handleInputChange}
              placeholder="아이디 입력"
            />
          </li>
          <li>
            <input 
              type="password"
              name="password"
              value={formData.password}
              onChange={handleInputChange}
              placeholder="비밀번호 입력"
            />
          </li>
          <li>
            <button type="submit">로그인</button>
          </li>
        </ul>
      </form>
      {/* 결과 메시지 출력 */}
      {result === "success" && (
        <p style={{color: 'blue'}}>환영합니다.</p>
      )}
      {result === "fail" && (
        <p style={{color: 'red'}}>아이디 또는 비밀번호가 일치하지 않습니다.</p>
      )}
    </div>
  )
}

export default SignIn;

실습 11-3. useEffect로 최초 실행 시 콘솔 출력

useEffect를 사용하여 컴포넌트가 처음 실행될 때 콘솔에 "페이지 로딩…"을 출력하세요.

정답 보기 
import { useEffect } from "react";

function Page() {
  useEffect(() => {
    console.log("페이지 로딩…");
  }, []); // 빈 배열 → 처음 한 번만 실행

  return <h2>페이지</h2>;
}

export default Page

의존성 배열을 []로 두면 최초 마운트 시 한 번만 실행된다.
