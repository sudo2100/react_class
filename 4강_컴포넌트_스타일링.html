1 리엑트 CSS — index.css vs App.css

🎯 학습목표
  • 리엑트 프로젝트에서 CSS 파일이 적용되는 범위를 이해한다.
  • 전역 스타일(index.css)과 컴포넌트 스타일(App.css)의 역할 차이를 구분한다.

📖 index.css — 프로젝트 전체 기본 스타일

프로젝트 전체에 적용되는 기본 스타일입니다. 다음과 같은 특징이 있습니다.

  • 모든 컴포넌트에 영향을 줍니다.
  • HTML 기본 스타일 초기화(reset) 또는 공통 스타일을 정의합니다.
  • 폰트, 배경, 기본 색상을 설정합니다.
💡 예제 — index.css 전역 스타일
src/index.css 
/* index.css */
body {
  margin: 0;
  font-family: Arial, sans-serif;
  background-color: #f5f5f5;
}
h1 {
  color: #333;
}

📖 App.css — 특정 컴포넌트 스타일

  • 특정 컴포넌트에만 적용됩니다.
  • 보통 App.jsx의 UI 스타일을 담당합니다.
💡 예제 — App.css 컴포넌트 스타일
src/App.css 
/* App.css */
.container {
  text-align: center;
  padding: 20px;
}
.button {
  background-color: blue;
  color: white;
}

구분index.cssApp.css

적용 대상전체 앱특정 컴포넌트
import 위치main.jsxApp.jsx

💡 정리 index.css는 main.jsx에서 import하여 앱 전체 기본값을 잡고, App.css는 App.jsx에서 import하여 화면 UI를 꾸미는 데 사용합니다. CSS는 실제로는 모두 전역으로 병합되지만, 파일을 목적에 따라 나누면 유지보수가 쉬워집니다.

2 인라인 스타일(inline style)

🎯 학습목표
  • JSX에서 style 속성에 자바스크립트 객체를 전달하는 방법을 익힌다.
  • CSS 속성명을 카멜케이스로 작성하는 규칙을 이해한다.

📖 인라인 스타일 규칙

  • style 속성에 문자열이 아닌 자바스크립트 객체를 할당합니다.
  • 객체의 키는 카멜케이스 형태로 작성합니다. (예: background-color → backgroundColor)
  • 중괄호가 이중({{ }})인 이유: 바깥 중괄호는 JSX 표현식, 안쪽 중괄호는 객체 리터럴입니다.
💡 예제 — 인라인 스타일 적용
src/App.jsx 
return (
  <>
    <div>
      {/* 인라인 스타일 적용 */}
      <h1
        style={{
          color: 'red',
          fontWeight: 'bold'
        }}
      >Hello, World!</h1>
    </div>
  </>
);
브라우저 출력

Hello, World!

3 뷰포트 단위와 미디어 쿼리(반응형)

🎯 학습목표
  • 뷰포트(viewport)의 개념과 vw/vh 단위를 이해한다.
  • 미디어 쿼리로 화면 크기에 따라 다른 스타일을 적용한다.

📖 뷰포트(Viewport) 단위

  • 뷰포트는 실제 내용이 표시되는 영역입니다.
  • PC 화면과 모바일 화면은 픽셀 표시 방법이 다르기 때문에, 뷰포트를 지정하지 않으면 모바일에서 의도한 대로 표시되지 않습니다.
  • 뷰포트를 지정하면 기기 화면에 맞춰 확대/축소해서 내용을 표시합니다.

CSS에서 크기를 지정할 때 px, %는 고정 폰트이고, 브라우저 비율에 따라 글자 크기가 변하는 가변 단위는 vw, vh입니다.

단위의미
vw (viewport width)1vw = 뷰포트 너비의 1% (너비 1200px일 때 5vw = 60px)
vh (viewport height)1vh = 뷰포트 높이의 1%

📖 미디어 쿼리(Media Query)

  • 접속하는 장치(미디어)에 따라 특정한 CSS 스타일을 사용하도록 합니다.
  • 반응형 웹디자인에서 가장 많이 사용하는 방식입니다. (가변 그리드 레이아웃, 플렉스박스 레이아웃 등)

기본 구문은 @media 미디어유형 [and 조건] * [and 조건] 형태입니다.

@media 미디어유형 [and 조건] [and 조건] { ... } 예) 미디어 유형이 'screen'이면서 최소 너비 768px, 최대 너비 1023px
예시 
@media screen and (min-width: 768px) and (max-width: 1023px) {
  /* .... */
}
💡 예제 — 화면 크기에 따라 배경색 변경
mq.html 
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>미디어 쿼리 예제</title>
<style> 
  @media screen and (max-width: 767px) {
    /* 화면 너비가 767px 이하일 때 적용 */
    body{
      background-color: lightcoral;
    }
    h1{font-size: 1.5rem;} /* 1.5 * 16 = 24px */
  }

  /* 화면 너비가 768px 이상일 때 적용 */
  @media screen and (min-width: 768px) {
    body{
      background-color: lightblue;
    }
    h1{font-size: 2rem;}
  }

  /* 화면 너비가 1100px 이상일 때 적용 */
  @media screen and (min-width: 1100px) {
    body{
      background-color: lightgreen;
    }
    h1{font-size: 2.5rem;}
  }
</style>
body 
<body>
  <h2>미디어 쿼리 예제</h2>
  <p>화면 크기에 따라 배경색이 변경됩니다.</p>
</body>
브라우저 출력
모바일(≤767px) → lightcoral(연분홍)
태블릿(≥768px) → lightblue(하늘색)
데스크톱(≥1100px) → lightgreen(연두색)

4 스타일 변수와 CSS 변수 — var()

🎯 학습목표
  • :root에 CSS 변수를 정의하고 var()로 재사용하는 방법을 익힌다.
  • 색상·여백 등 반복되는 값을 변수로 관리하는 이점을 이해한다.

📖 CSS 변수 정의 및 사용

var() 함수는 "CSS 변수"의 값을 다른 속성의 값으로 지정할 때 사용합니다. 변수는 보통 :root(문서 최상위)에 --변수명 형태로 정의합니다.

💡 예제 — CSS 변수 정의 (:root)
css-style.html 
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>css 스타일</title>
  <style>
    /* css 변수 정의 */
    :root{
      /* 글자색 */
      --red-color: rgb(212, 60, 60);

      /* 배경색 */
      --green-color: rgb(45, 238, 45);

      /* 여백 1rem = 16px */
      --my-2: 0.5rem;
      --my-3: 1rem;
    }
💡 예제 — var()로 변수 사용
css-style.html (이어서) 
    h2{
      /* color: red; */
      color: var(--red-color);
    }
    div{
      width: 100px;
      height: 100px;
      /*background-color: #0f0;*/
      background-color: var(--green-color);
      /*margin: 10px;*/
      margin: var(--my-3);
      display: inline-block;
    }
  </style>
</head>
<body>
  <h2>스타일 변수</h2>
  <div></div>
  <div></div>
</body>
브라우저 출력

스타일 변수

💡 정리 한 번 정의한 --red-color, --my-3 같은 변수를 여러 곳에서 var()로 재사용하면, 값을 :root 한 곳에서만 바꿔도 전체 스타일이 일괄 변경됩니다.

5 Flexbox 레이아웃 — flex-direction

🎯 학습목표
  • Flexbox의 컨테이너/아이템 구조와 주축 개념을 이해한다.
  • flex-direction으로 가로/세로 배치를 전환한다.

📖 플렉스 박스(Flex Box) 레이아웃

  • 수평이나 수직 방향 중 하나를 주축으로 정하고 박스를 배치합니다.
  • 여유 공간이 생길 경우 너비나 높이를 적절하게 늘리거나 줄일 수 있습니다.
┌──────── flex container ────────┐ │ [flex item] [flex item] [flex item] │ └────────────────────────────────┘
💡 예제 — flex-direction: row / column
flex.html — style 
.container {
  display: flex;
  flex-direction: row;    /* 아이템을 가로 방향으로 배치 */
  flex-direction: column; /* 아이템을 세로 방향으로 배치 */
  gap: 16px;              /* 아이템 사이의 간격 */
}
.box {
  width: 100px;
  height: 100px;
  background-color: lightcoral;
}
flex.html — body 
<div class="container">
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
</div>
브라우저 출력

row (가로 배치)

column (세로 배치)

💡 정리 마지막에 선언된 값이 실제로 적용되므로, 위 코드에서는 column이 최종 적용됩니다. 실제 사용 시에는 원하는 하나의 flex-direction만 남겨 둡니다.

6 Flexbox 정렬 — justify-content / align-items

🎯 학습목표
  • justify-content로 주축(main axis) 정렬을 지정한다.
  • align-items로 교차축(cross axis) 정렬을 지정한다.

📖 justify-content — 주축 정렬

주축(main axis) 방향의 정렬 방법을 지정합니다.

💡 예제 — justify-content 옵션
flex2.html — style 
.container {
  display: flex;
  justify-content: center;        /* 아이템을 가로 방향으로 중앙 정렬 */
  justify-content: flex-start;    /* 아이템을 가로 방향으로 시작 위치에 정렬 */
  justify-content: space-between; /* 아이템을 가로 방향으로 양 끝에 정렬 */
  justify-content: space-around;  /* 아이템을 가로 방향으로 고르게 분배 */
  gap: 16px;                      /* 아이템 사이의 간격 */
}
.box {
  width: 100px;
  height: 100px;
  background-color: skyblue;
}

space-between

7 styled-components 기초

🎯 학습목표
  • CSS-in-JS 개념과 styled-components의 역할을 이해한다.
  • props를 이용한 동적 스타일링 문법을 익힌다.

📖 styled-components 란?

  • CSS를 JavaScript 안에서 작성할 수 있게 해주는 대표적인 CSS-in-JS 라이브러리입니다.
  • 기존처럼 .css 파일을 따로 만드는 대신, JS 파일 안에서 스타일 + 컴포넌트를 함께 작성합니다.
설치 
npm install styled-components
package.json — dependencies 
"dependencies": {
  "axios": "^1.14.0",
  "react": "^19.2.4",
  "react-dom": "^19.2.4",
  "styled-components": "^6.3.12"
},

📖 동적 스타일링 문법

${props => props.color}는 styled-components의 동적 스타일링 문법입니다.

  • ${} = JavaScript 템플릿 리터럴 (백틱 내에서 JS 실행)
  • props => props.color = 화살표 함수로 props 객체에서 color 값 추출
  • 결과 = 컴포넌트에 전달된 color prop을 CSS 값으로 사용
💡 예제 — 버튼 컴포넌트 정의(Button.jsx)
src/Button.jsx 
import styled from 'styled-components';

const Button = styled.button`
  margin: 5px;
  padding: 8px 16px;
  border: 1px solid #ccc;
  border-radius: 8px;
  font-size: 1rem;
  line-height: 1.5; // 버튼의 높이를 텍스트의 높이에 맞게 조정

  // props를 이용하여 스타일을 동적으로 변경
  color: ${props => props.color || 'black'};
  background-color: ${props => props.backgroundColor || 'white'};

  // primary prop이 true일 때 추가 스타일 적용
  ${props => props.primary && `
    color: white;
    background-color: purple;
  `}
`;
💡 예제 — 버튼 사용(ButtonSample.jsx)
src/ButtonSample.jsx 
const ButtonSample = () => {
  return (
    <>
      <Button>기본 버튼</Button>
      {/* props를 이용하여 스타일을 동적으로 변경 */}
      <Button color="green" backgroundColor="yellow">
        녹색 버튼
      </Button>
      {/* primary prop이 true일 때 추가 스타일 적용 */}
      <Button primary>보라 버튼</Button>
    </>
  );
};

export default ButtonSample;

8 styled-components 페이지 스타일링과 확장

🎯 학습목표
  • styled.div, styled.h1 등으로 레이아웃 컴포넌트를 만든다.
  • styled(기존컴포넌트)로 스타일을 상속(확장)한다.
💡 예제 — Main 페이지 스타일 정의
src/MainPage.jsx 
import styled from 'styled-components';

const Wrapper = styled.div`
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  // 100vh는 브라우저 창의 높이를 의미, 예) 창 높이 1000px일때,
  // 50vh(viewport height) = 50*(창높이/100) = 500px
  height: 100vh;

9 styled-components 실전 — Blocks 모형

🎯 학습목표
  • props로 색상을 전달해 동적으로 스타일되는 블록을 만든다.
  • useState와 onClick을 결합해 클릭한 색상을 표시한다.
💡 예제 — Blocks 컴포넌트 로직
src/Blocks.jsx 
const Blocks = () => {
  // 클릭한 블록의 색상을 저장하는 상태
  const [clicked, setClicked] = useState(null);

  const handleClick = (color) => {
    setClicked(color);
  };

  return (
    <Wrapper>
      <Block
        color="#f00"
        onClick={() => handleClick('red')}
      />
      <Block
        color="#0f0"
        onClick={() => handleClick('green')}
      />
      <Block
        color="#00f"
        onClick={() => handleClick('blue')}
      />
      {clicked && <p>클릭한 색상: {clicked}</p>}
    </Wrapper>
  );
};

export default Blocks;
💡 예제 — Wrapper / Block 스타일 (props 동적)

  height: 100px;

`;
