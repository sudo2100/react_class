1 TypeScript 개요와 설치·실행

🎯 학습목표
  • TypeScript가 무엇이고 JavaScript와 어떤 관계인지 설명할 수 있다.
  • TypeScript를 사용하는 이유와 실무 현황을 이해한다.
  • 타입을 명시한 변수 선언 문법을 읽을 수 있다.
  • TypeScript 설치와 컴파일·실행 흐름을 이해한다.
  • 타입이 없을 때 발생하는 JavaScript의 대표적 문제를 안다.

📖 TypeScript란?

TypeScript는 자바스크립트를 기반으로 한 정적 타입 언어로, Microsoft에서 개발했습니다. 자바스크립트의 유연함에 정적 타입 시스템이라는 안전망을 더한 언어입니다. 쉽게 말하면 JavaScript + 타입 기능이라고 보면 됩니다.

  • 타입 검사(Type Checking) — 잘못된 타입 사용을 실행 전에 잡아냅니다.
  • 최신 문법 지원(ES6+)
  • 더 강력한 개발 도구 지원 — 자동완성, 오류 탐지
💡 정리 작성한 TypeScript 코드는 결국 JavaScript로 변환(컴파일)되어 실행됩니다.

📖 타입을 명시한 변수 선언

변수 선언 예 
let name: string = "장그래";
let age: number = 30;
let isStudent: boolean = false;

실무에서는 React 프로젝트(특히 협업), 대규모 웹 서비스, 유지보수가 중요한 프로젝트에서 널리 쓰이며, 요즘은 React + TypeScript 조합이 거의 표준입니다.

📖 자바스크립트의 문제점

  • 자료형의 구분이 명확하지 않아서 [숫자 + 문자]도 계산됩니다.
  • 변수 선언이나 함수 정의 시 호이스팅(Hoisting) 문제가 발생합니다.
💡 예제 — 타입이 없을 때 생기는 혼란
problem.js 
// javascript의 약점
console.log(2 + '3');            // "23"
console.log(typeof (2 + '3'));   // "string"

// Hoisting은 JavaScript 엔진이 코드 실행 전에 함수와
// 변수 선언을 스코프의 최상단으로 끌어올리는 동작입니다
console.log(a);   // undefined(에러 아님)
var a = 2;

// 참조 오류 발생
// console.log(b);
let b = 3;

// 함수 선언문은 호이스팅이 발생합니다
add(10, 11);   // 21

function add(x, y) {
    return x + y;
}

string

undefined

2 기본 타입과 any

🎯 학습목표
  • string·number·boolean·배열 등 기본 타입을 선언할 수 있다.
  • 배열 타입의 두 가지 표기법(T[], Array<T>)을 안다.
  • any의 용도와 남용하면 안 되는 이유를 이해한다.
💡 예제 — 기본 타입
index.ts 
// string - 문자열
let message: string = "Hello, TypeScript!";
console.log(message);

// number - 숫자
let age: number = 30;
console.log(`나이: ${age}`);

// boolean - 불리언(참/거짓)
let isStudent: boolean = true;
console.log(`학생인가요? ${isStudent}`);

// 배열 - Array
let carts: string[] = ["사과", "바나나", "오렌지"];
console.log(`장바구니: ${carts.join(", ")}`);

let carts2: Array<string> = ["사과", "바나나", "오렌지"];
console.log(`장바구니 2: ${carts2.join(", ")}`);
💡 정리 string[]와 Array<string>는 동일한 의미입니다. Array<T>는 제네릭 표기법입니다.

📖 기본 타입 — any

any는 이름 그대로 어떤 타입의 값도 담을 수 있는 타입입니다.

  • 할당 제한 없음: 숫자, 문자열, 배열, 객체, 함수 등 무엇이든 대입할 수 있습니다.
  • 타입을 도저히 알 수 없는 동적 콘텐츠: 서드파티 라이브러리에서 오는 복잡한 데이터나 구조를 알 수 없는 값을 다룰 때 사용합니다.
💡 예제 — any
index.ts 
// any - 모든 타입 허용 (사용 자제)
let value: any = 10;

value = "Hello";   // OK
value = true;      // OK

console.log(`value = ${value}`);
⚠️ 주의 any를 남용하면 타입 검사의 이점이 사라집니다. 꼭 필요한 경우에만 제한적으로 사용하세요.
✏️ 실습문제

실습 2-1. 프로필 변수 선언

이름(string), 나이(number), 취미 목록(string 배열)을 담는 변수를 타입을 명시해 선언하고 콘솔에 출력하세요.

정답 보기 
let userName: string = "홍길동";
let userAge: number = 27;
let hobbies: string[] = ["독서", "코딩", "러닝"];

console.log(`${userName}(${userAge})의 취미: ${hobbies.join(", ")}`);

3 interface와 type(타입 별칭)

🎯 학습목표
  • interface로 객체의 구조(속성과 타입)를 정의할 수 있다.
  • readonly와 선택적 속성(?)의 의미를 이해한다.
  • interface와 type의 차이를 표로 비교할 수 있다.
  • type 별칭으로 객체·유니온 타입을 정의할 수 있다.
  • interface와 type을 함께 사용하는 예제를 읽을 수 있다.

📖 interface란?

TypeScript의 interface는 객체의 구조(형태)를 정의하는 설계도입니다. 쉽게 말하면 "이 객체는 어떤 속성과 타입을 가져야 한다"를 미리 정해 놓는 것입니다.

기본 형태 
interface Member {
  name: string;
  age: number;
}

const member1: Member = {
  name: "이강",
  age: 21,
};

📖 interface vs type 별칭 비교

두 문법 모두 객체의 구조를 정의하는 데 사용되지만, 아래와 같은 차이가 있습니다.

특징InterfaceType Alias
선언 방식interface User { ... }type User = { ... }
확장 방식extends 키워드 사용교차 타입(&) 사용
선언 병합가능 (같은 이름으로 중복 선언 시 합쳐짐)불가능 (중복 선언 시 에러)
객체 외 타입불가능 (객체 형태만 가능)가능 (Primitive, Union, Tuple 등)
계산된 속성가능가능
💡 예제 — interface로 객체 만들기
interface_ex.ts 
// 인터페이스(interface) 정의
interface Person{
  name: string,
  age: number
}

// 인터페이스를 활용한 객체 생성
let person1: Person = {
  name: "정윤하",
  age: 35
}

let person2: Person = {
  name: "박재명",
  age: 30
}

// 출력
console.log(`이름: ${person1.name}, 나이: ${person1.age}` );
console.log(`이름: ${person2.name}, 나이: ${person2.age}` );
💡 예제 — readonly와 선택적 속성(?)
interface_ex.ts 
// readonly 속성은 객체가 생성된 후에는 변경할 수 없는 속성
// 선택적 속성(?)은 객체에 있을 수도 있고 없을 수도 있는 속성
interface User {
    readonly id: number;
    name: string;
    age?: number; // age는 선택적 속성
}

let user1: User = {id: 1, name: "김철수"};

let user2: User = {id: 2, name: "이영희", age: 28};

console.log(`이름: ${user1.name}`);

user2.name = "박상희"; // name 속성은 변경 가능
console.log(`이름: ${user2.name}, 나이: ${user2.age}`);

user1.id = 3; // 오류: id는 readonly 속성이므로 변경할 수 없습니다.
💡 정리 readonly는 재할당을 막고, ?는 해당 속성을 생략할 수 있게 만듭니다.

📖 type이란?

TypeScript의 type은 데이터의 형태를 정의하는 또 다른 방법입니다. interface와 비슷하지만, 더 유연하고 다양한 타입(유니온, 튜플, 원시 타입 등)을 표현할 수 있는 것이 핵심입니다.

기본 형태 
type Member = {
  id: number;
  name: string;
  age: number;
};

타입 별칭(Type Alias)은 타입에 새 이름(별명)을 붙이는 것입니다. type 이름 = 타입 형식으로 쓰고, 한 번 정의한 이름은 그 타입 대신 어디서든 쓸 수 있습니다.

type MemberRole = "admin" | "user";   // Union 타입에 이름 붙이기
type Point = [number, number];        // 튜플에 이름 붙이기
type Member = { id: number; name: string; role: MemberRole }; // 객체 타입에 이름 붙이기
💡 예제 — Union 타입과 type
type_ex.ts 
// Union Type: 여러 타입 중 하나를 선택할 수 있는 타입
type MemberRole = "admin" | "user";

type Member = {
  id: number;
  name: string;
  age?: number;
  role: MemberRole;
}

const member1: Member = {
  id: 1,
  name: "우영우",
  role: "admin"
};

const member2: Member = {
  id: 2,
  name: "이준호",
  age: 30,
  role: "user"
};

console.log(`회원1 - ID: ${member1.id}, 이름: ${member1.name}, 권한: ${member1.role}`);
console.log(`회원2 - ID: ${member2.id}, 이름: ${member2.name}, 나이: ${member2.age}, 권한: ${member2.role}`);
💡 예제 — interface와 type을 함께 쓰기
multi_ex.ts 
// 학점 정의
type Grade = "A" | "B" | "C" | "D" | "F";

// 과목 정의
interface Course {
    courseId: number;
    courseName: string;
    grade?: Grade; // 선택적 속성
}

// 학생 정의
interface Student {
    id: number;
    name: string;
    subjects: Course[]; // 학생이 수강하는 과목 목록
}

// 학생 객체 생성
let student1: Student = {
    id: 1,
    name: "김선화",
    subjects: [
        { courseId: 101, courseName: "수학", grade: "A" },
        { courseId: 102, courseName: "영어", grade: "B" },
    ]
};

// 학생 정보 출력
console.log(`학생명: ${student1.name}`);
student1.subjects.forEach(subject => {
    console.log(`과목명: ${subject.courseName}, 학점: ${subject.grade}`);
});
브라우저 출력

학생명: 김선화

과목명: 수학, 학점: A

과목명: 영어, 학점: B

4 함수의 타입

🎯 학습목표
  • 매개변수와 반환값에 타입을 지정할 수 있다.
  • 반환값이 없는 함수에 void를 명시할 수 있다.
  • 객체를 반환하는 함수의 타입을 작성할 수 있다.
💡 예제 — return이 있는 함수
function_ex.ts 
/*function sub(x: number, y: number): number {
  return x - y;
}*/

// 익명 함수
/*const sub = function (x: number, y: number): number {
  return x - y;
};*/

// 화살표 함수
const sub = (x: number, y: number): number => {
  return x - y;
};

const result = sub(10, 5);
console.log(`10 - 5 = ${result}`);
💡 예제 — return이 없는 함수(void)
function_ex.ts 
/*function greet(name: string): void {
  console.log(`Hello, ${name}!`);
}*/

const greet = (name: string): void => {
  console.log(`Hello, ${name}!`);
}
greet("TypeScript");
💡 정리 아무 값도 반환하지 않는 함수의 반환 타입은 void로 명시합니다.
💡 예제 — 객체를 반환하는 함수
function_ex.ts 
/*function createUser(id:number, name:string):{id: number; name: string}{
  return {id, name};
}*/

const createUser = (id:number, name:string):
    {id: number; name: string} => {
  return {id, name};
}

const user_kim = createUser(1, "김기용");
console.log(`사용자 ID: ${user_kim.id}, 이름: ${user_kim.name}`);

5 제네릭과 유틸리티 타입

🎯 학습목표
  • 제네릭(Generic)이 무엇인지 이해한다.
  • Omit, Record 등 대표적 유틸리티 타입을 안다.
  • Record<K, T>로 키·값 타입을 정의할 수 있다.

📖 제네릭(Generic)

제네릭은 타입에 이름을 붙여 재사용 가능하게 만드는 기능입니다. React 훅에서도 자주 사용됩니다.

const [value, setValue] = useState<number>(0);
const [isLoggedIn, setIsLoggedIn] = useState<boolean>(false);
💡 예제 — 제네릭 배열 · 함수
example.ts 
// 1. 제네릭 배열 : Array<T>는 T[]와 같은 의미
const scores: Array<number> = [90, 85, 100];
console.log(scores.join(", "));

// 2. 제네릭 함수 : <T>는 호출할 때 정해지는 타입 자리
function getFirst<T>(arr: T[]): T {
  return arr[0];
}

const num = getFirst<number>([10, 20, 30]);       // T = number
const str = getFirst<string>(["사과", "바나나"]); // T = string
const auto = getFirst([true, false]);             // 타입 추론 → T = boolean

console.log(num, str, auto);
실행 결과

90, 85, 100

10 사과 true

💡 정리 제네릭은 타입을 매개변수처럼 받습니다. 함수를 한 번만 만들고, 사용할 때 <number>, <string>처럼 타입만 바꿔 재사용할 수 있습니다.

📖 유틸리티 타입

타입스크립트는 다양한 유틸리티 타입을 기본 제공하여 타입 선언을 더 간결하고 유연하게 만들 수 있게 돕습니다. 대표적으로 Omit, Record 등이 있습니다.

const handleAddProduct = (newProduct: Omit<Product, 'id'>) => { }
// Product 타입에서 id 속성을 제외한 나머지 속성들로 구성된 타입입니다.
// Omit<T, K> - 선택한 속성(K)을 제외한 나머지를 가져옵니다.

📖 Record<K, T>란?

Record<Keys, Type>는 객체의 키(Key)와 값(Value)의 타입을 간편하게 정의할 수 있게 도와주는 유틸리티 타입입니다.

  • K (Keys): 객체의 속성 키로 사용할 타입 (보통 문자열 리터럴의 유니온이나 string, number 등).
  • T (Type): 각 키에 할당될 값의 타입.
type Fruit = 'apple' | 'banana' | 'orange';

const prices: Record<Fruit, number> = {
  apple: 2000,
  banana: 1500,
  orange: 1000
}
💡 예제 — Record로 동적 키/값
record_ex.ts 
// 동적 키와 값
type StringMap = Record<string, string>;

const translations: StringMap = {
  hello: '안녕하세요',
  goodbye: '안녕히 가세요',
};

// 출력
console.log(translations.hello);   // '안녕하세요'
console.log(translations.goodbye); // '안녕히 가세요'
💡 예제 — Record로 특정 키만 허용
record_ex.ts 
// 특정 키만 허용
type Fruit = 'apple' | 'banana' | 'orange';

const prices: Record<Fruit, number> = {
  apple: 2000,
  banana: 1500,
  orange: 1000
}

// 사과의 가격
console.log(`사과 가격: ${prices.apple}`);

// 전체 출력
for (const fruit in prices) {
  // fruit는 string 타입이므로 Fruit 타입으로 단언

import { useParams, useNavigate } from 'react-router-dom';
import { useState, useEffect } from 'react';
import axios from 'axios';
import type { Todo } from './Todos'; // Todos.tsx에서 Todo 인터페이스 가져오기

const TodoDetail = () => {
  // /todos/2 => id = "2"(string)
  const { id } = useParams<{ id: string }>(); // URL에서 id 파라미터 가져오기
  const navigate = useNavigate(); // 페이지 이동을 위한 hook
  const [todo, setTodo] = useState<Todo | null>(null);

  useEffect(() => {
    const fetchTodo = async () => {
      try {
        const response =
          await axios.get(`https://jsonplaceholder.typicode.com/todos/${id}`);
        setTodo(response.data); // API 응답에서 데이터를 가져와 상태 업데이트
      } catch (error) {
        alert('할 일 정보를 가져오는 중 오류가 발생했습니다.'); // 오류 메시지 표시
      }
    }
    fetchTodo();
  }, [id]);
