1 useReducer() — TypeScript로 상태 관리

🎯 학습목표
  • State와 Action의 타입을 interface와 Union 타입으로 정의할 수 있다.
  • 타입이 지정된 리듀서 함수 (state, action) => 새 state를 작성할 수 있다.
  • 잘못된 dispatch를 TypeScript가 미리 잡아 주는 이유를 이해한다.

📖 useReducer에 타입을 붙이는 3단계

단계무엇을방법
1State 타입interface BankState { balance: number; ... }
2Action 타입Union 타입으로 가능한 액션을 모두 나열 { type: "DEPOSIT"; amount: number } | { type: "RESET" }
3리듀서 함수(state: BankState, action: BankAction): BankState

리듀서에 타입만 지정하면 useReducer(bankReducer, initialState)의 state와 dispatch 타입은 자동으로 추론됩니다. switch (action.type) 안에서는 각 case에 맞게 action의 타입이 좁혀지므로(타입 좁히기), DEPOSIT에서는 action.amount를 쓸 수 있고 RESET에서는 쓸 수 없습니다.

💡 예제 — 타입이 지정된 은행 리듀서
src/bankReducer.ts 
// 1. State 타입 : 상태의 모양
export interface BankState {
  balance: number;
  history: string[];
}

// 2. Action 타입 : Union으로 가능한 액션을 모두 나열
export type BankAction =
  | { type: "DEPOSIT"; amount: number }
  | { type: "WITHDRAW"; amount: number }
  | { type: "RESET" };

// 초기값도 BankState 타입을 따름
export const initialState: BankState = {
  balance: 0,
  history: [],
};

// 3. 리듀서 : (현재 상태, 액션) => 새 상태
export function bankReducer(state: BankState, action: BankAction): BankState {
  switch (action.type) {
    case "DEPOSIT":
      // 이 case 안에서 action은 { type: "DEPOSIT"; amount: number }로 좁혀짐
      return {
        balance: state.balance + action.amount,
        history: [...state.history, `입금 ${action.amount.toLocaleString()}원`],
      };
    case "WITHDRAW":
      if (action.amount > state.balance) {
        alert("잔액이 부족합니다.");
        return state;
      }
      return {
        balance: state.balance - action.amount,
        history: [...state.history, `출금 ${action.amount.toLocaleString()}원`],
      };
    case "RESET":
      // RESET에는 amount가 없으므로 action.amount를 쓰면 타입 오류
      return initialState;
    default:
      return state;
  }
}
💡 예제 — Bank 컴포넌트에서 dispatch
src/Bank.tsx 
import { useReducer, useState } from "react";
import { bankReducer, initialState } from "./bankReducer";

const Bank = () => {
  // state는 BankState, dispatch는 BankAction만 받도록 자동으로 타입이 정해짐
  const [state, dispatch] = useReducer(bankReducer, initialState);
  const [amount, setAmount] = useState<number>(0);

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setAmount(Number(e.target.value) || 0);
  };

  return (
    <div>
      <h2>TypeScript 은행</h2>
      <h3>잔액: {state.balance.toLocaleString()}원</h3>

      <input type="number" value={amount} step={1000} onChange={handleChange} />
      <button onClick={() => dispatch({ type: "DEPOSIT", amount })}>입금</button>
      <button onClick={() => dispatch({ type: "WITHDRAW", amount })}>출금</button>
      <button onClick={() => dispatch({ type: "RESET" })}>초기화</button>

      {/* dispatch({ type: "DEPOSIT" })       → amount 누락 오류
          dispatch({ type: "TRANSFER", ... }) → 없는 액션 오류 */}

      <ul>
        {state.history.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  );
};

export default Bank;

✏️ 실습문제

실습 1-1. 카운터 리듀서에 타입 지정하기

count 하나를 가진 State와 INCREMENT · DECREMENT · SET(value: number) 세 가지 Action을 타입으로 정의하고, useReducer로 카운터를 만드세요.

정답 보기 
import { useReducer } from "react";

interface CounterState {
  count: number;
}

type CounterAction =
  | { type: "INCREMENT" }
  | { type: "DECREMENT" }
  | { type: "SET"; value: number };

function counterReducer(state: CounterState, action: CounterAction): CounterState {
  switch (action.type) {
    case "INCREMENT":
      return { count: state.count + 1 };
    case "DECREMENT":
      return { count: state.count - 1 };
    case "SET":
      return { count: action.value };
    default:
      return state;
  }
}

const Counter = () => {
  const [state, dispatch] = useReducer(counterReducer, { count: 0 });

  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: "INCREMENT" })}>+1</button>
      <button onClick={() => dispatch({ type: "DECREMENT" })}>-1</button>
      <button onClick={() => dispatch({ type: "SET", value: 0 })}>0으로</button>
    </div>
  );
};

export default Counter;

2 useContext() — TypeScript로 전역 데이터 공유

🎯 학습목표
  • createContext<타입 | null>(null)로 Context 값의 타입을 지정할 수 있다.
  • Provider의 children을 ReactNode 타입으로 받을 수 있다.
  • 커스텀 훅에서 null 검사를 처리해 안전하게 Context를 꺼내 쓸 수 있다.
  • useReducer(단원 1)와 Context를 결합해 장바구니 전역 상태를 만들 수 있다.

📖 Context에 타입을 붙이는 방법

단계JavaScript (7강)TypeScript
값의 타입-interface CartContextType { cart: CartItem[]; ... }
만들기createContext()createContext<CartContextType | null>(null)
공급하기({ children })({ children }: { children: ReactNode })
꺼내 쓰기useContext(CartContext)useCart() 안에서 null 검사 후 반환

Provider 밖에서 useContext를 호출하면 값이 없으므로 기본값을 null로 둡니다. 그러면 꺼낸 값의 타입이 CartContextType | null이 되어 매번 null 검사가 필요한데, 커스텀 훅에서 한 번만 검사하면 사용하는 컴포넌트는 항상 CartContextType으로 받을 수 있습니다.

💡 예제 — 장바구니 Context (타입 정의 · 리듀서 · Provider · 커스텀 훅)
App └ CartProvider → cart, dispatch, totalCount, totalPrice 제공 ├ Header → totalCount ├ ProductList → dispatch (ADD) └ Cart → cart, dispatch, totalPrice
src/CartContext.tsx 
import { createContext, useContext, useReducer } from "react";
import type { ReactNode } from "react";

// 1. 데이터 타입
export interface Product {
  id: number;
  name: string;
  price: number;
}

export interface CartItem extends Product {
  qty: number; // Product의 속성 + 수량
}

type CartAction =
  | { type: "ADD"; product: Product }
  | { type: "DECREASE"; id: number }
  | { type: "REMOVE"; id: number }
  | { type: "CLEAR" };

// 2. Context에 담을 값의 타입
interface CartContextType {
  cart: CartItem[];
  dispatch: React.Dispatch<CartAction>;
  totalCount: number;
  totalPrice: number;
}

function cartReducer(state: CartItem[], action: CartAction): CartItem[] {
  switch (action.type) {
    case "ADD": {
      const found = state.find((item) => item.id === action.product.id);
      if (found) {
        return state.map((item) =>
          item.id === action.product.id ? { ...item, qty: item.qty + 1 } : item
        );
      }
      return [...state, { ...action.product, qty: 1 }];
    }
    case "DECREASE":
      return state
        .map((item) => (item.id === action.id ? { ...item, qty: item.qty - 1 } : item))
        .filter((item) => item.qty > 0);
    case "REMOVE":
      return state.filter((item) => item.id !== action.id);
    case "CLEAR":
      return [];
    default:
      return state;
  }
}

// 3. Context 생성 : Provider 밖에서는 값이 없으므로 null 허용
const CartContext = createContext<CartContextType | null>(null);

// 4. Provider : children의 타입은 ReactNode
export function CartProvider({ children }: { children: ReactNode }) {
  const [cart, dispatch] = useReducer(cartReducer, []);

  const totalCount = cart.reduce((sum, item) => sum + item.qty, 0);
  const totalPrice = cart.reduce((sum, item) => sum + item.price * item.qty, 0);

  return (
    <CartContext.Provider value={{ cart, dispatch, totalCount, totalPrice }}>
      {children}
    </CartContext.Provider>
  );
}

// 5. 커스텀 훅 : null 검사를 한 곳에서 처리 → 사용하는 쪽은 CartContextType으로 받음
export function useCart(): CartContextType {
  const context = useContext(CartContext);
  if (!context) {
    throw new Error("useCart는 CartProvider 안에서만 사용할 수 있습니다.");
  }
  return context;
}

실습 2-1. 테마 Context에 타입 지정하기

"light" | "dark" 두 값만 가지는 theme과 toggleTheme 함수를 Context로 공유하세요. ThemeProvider와 useTheme() 커스텀 훅을 만들고, 버튼을 누르면 테마가 바뀌게 합니다.

정답 보기 
import { createContext, useContext, useState } from "react";
import type { ReactNode } from "react";

type Theme = "light" | "dark";

interface ThemeContextType {
  theme: Theme;
  toggleTheme: () => void;
}

const ThemeContext = createContext<ThemeContextType | null>(null);

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>("light");
  const toggleTheme = () => setTheme((prev) => (prev === "light" ? "dark" : "light"));

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme(): ThemeContextType {
  const context = useContext(ThemeContext);
  if (!context) throw new Error("useTheme는 ThemeProvider 안에서만 사용할 수 있습니다.");
  return context;
}

export const ThemeButton = () => {
  const { theme, toggleTheme } = useTheme();
  return (
    <div>
      <p>현재 테마: {theme}</p>
      <button onClick={toggleTheme}>테마 변경</button>
    </div>
  );
};

3 Redux Toolkit — TypeScript로 전역 상태 관리

🎯 학습목표

💡 예제 — slice · store · 타입 지정 훅
src/store/counterSlice.ts 
import { createSlice } from '@reduxjs/toolkit'
import type { PayloadAction } from '@reduxjs/toolkit'

// 1. State 타입
interface CounterState {
  count: number
}

const initialState: CounterState = {
  count: 0,
}

const counterSlice = createSlice({
  name: 'counter',
  initialState,
  reducers: {
    increment: (state) => {
      state.count += 1
    },
    decrement: (state) => {
      state.count -= 1
    },
    reset: (state) => {
      state.count = 0
    },
    // 2. payload가 있는 액션 : PayloadAction<payload의 타입>
    incrementByAmount: (state, action: PayloadAction<number>) => {
      state.count += action.payload
    },
  },
})

export const { increment, decrement, reset, incrementByAmount } = counterSlice.actions
export default counterSlice.reducer
src/store/index.ts 
import { configureStore } from '@reduxjs/toolkit'
import counterReducer from './counterSlice'

export const store = configureStore({
  reducer: {
    counter: counterReducer,
  },
})

src/store/cartSlice.ts 
import { createSlice } from '@reduxjs/toolkit'
import type { PayloadAction } from '@reduxjs/toolkit'
import type { RootState } from './index'

// 1. 데이터 타입 (단원 2와 같음)
export interface Product {
  id: number
  name: string
  price: number
}

export interface CartItem extends Product {
  qty: number
}

interface CartState {
  items: CartItem[]
}

const initialState: CartState = {
  items: [],
}

const cartSlice = createSlice({
  name: 'cart',
  initialState,
  reducers: {
    // 2. 액션마다 payload 타입 지정
    //    RTK는 내부에서 immer를 사용하므로 state를 직접 고치는 문법을 써도 불변성이 지켜짐
    addItem: (state, action: PayloadAction<Product>) => {
      const found = state.items.find((item) => item.id === action.payload.id)
      if (found) {
        found.qty += 1
      } else {
        state.items.push({ ...action.payload, qty: 1 })
      }
    },
    decreaseItem: (state, action: PayloadAction<number>) => {
      const found = state.items.find((item) => item.id === action.payload)
      if (!found) return
      found.qty -= 1
      if (found.qty === 0) {
        state.items = state.items.filter((item) => item.id !== action.payload)
      }
    },
    removeItem: (state, action: PayloadAction<number>) => {
      state.items = state.items.filter((item) => item.id !== action.payload)
    },
    clearCart: (state) => {
      state.items = []
    },
  },
})

export const { addItem, decreaseItem, removeItem, clearCart } = cartSlice.actions
export default cartSlice.reducer

// 3. selector : state에서 계산한 값을 꺼내는 함수 (파생 값)
export const selectCartItems = (state: RootState) => state.cart.items
export const selectTotalCount = (state: RootState) =>
  state.cart.items.reduce((sum, item) => sum + item.qty, 0)
export const selectTotalPrice = (state: RootState) =>
  state.cart.items.reduce((sum, item) => sum + item.price * item.qty, 0)

💡 예제 — 장바구니 store 만들기

단원 2 · 3과 같은 장바구니입니다. 상태(items)와 변경 함수(addItem 등)를 CartStore 타입 하나에 정의합니다.

src/store/useCartStore.ts 
import { create } from 'zustand'

// 1. 데이터 타입 (단원 2 · 3과 같음)
export interface Product {
  id: number
  name: string
  price: number
}

export interface CartItem extends Product {
  qty: number
}

// 2. store 타입 : 상태 + 상태를 바꾸는 함수를 한 곳에 정의
interface CartStore {
  items: CartItem[]
  addItem: (product: Product) => void
  decreaseItem: (id: number) => void
  removeItem: (id: number) => void
  clearCart: () => void
}

// 3. store 생성 : create<타입>()((set) => ({ ... }))
//    set(함수) : 이전 state를 받아 바꿀 부분만 반환
export const useCartStore = create<CartStore>()((set) => ({
  items: [],

  addItem: (product) =>
    set((state) => {
      const found = state.items.find((item) => item.id === product.id)
      if (found) {
        return {
          items: state.items.map((item) =>
            item.id === product.id ? { ...item, qty: item.qty + 1 } : item
          ),
        }
      }
      return { items: [...state.items, { ...product, qty: 1 }] }
    }),

  decreaseItem: (id) =>
    set((state) => ({
      items: state.items
        .map((item) => (item.id === id ? { ...item, qty: item.qty - 1 } : item))
        .filter((item) => item.qty > 0),
    })),

  removeItem: (id) =>
    set((state) => ({ items: state.items.filter((item) => item.id !== id) })),

  clearCart: () => set({ items: [] }),
}))
💡 정리 create<CartStore>()((set) => ...)처럼 괄호를 두 번 쓰는 것이 TypeScript에서 Zustand를 쓰는 공식 방법입니다. set에 함수를 넘기면 이전 state를 받아 바꿀 부분만 반환하면 되고, 나머지 값은 자동으로 유지됩니다.
